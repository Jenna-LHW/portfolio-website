# My Portfolio Website

A personal portfolio site built with plain HTML, CSS, and JavaScript — no framework, no build step. It showcases my background as a Computer Science student, my experience, skills, and my project work.

**Live site:** https://jenna-lhw.netlify.app/

---

## Features

- A splash screen that plays once per session on first load
- A home page, project page, about page and contact page
- A contact form wired up with [Netlify Forms](https://docs.netlify.com/forms/setup/) — no backend required

## Tech stack

- HTML5 / CSS3 (no framework)
- Vanilla JavaScript (`fetch` for partials, no bundler)
- [Devicon](https://devicon.dev/) for tech icons in the splash screen
- Hosted on [Netlify](https://www.netlify.com/), deployed from this repo

## Deployment

Deployed via Netlify, connected directly to this GitHub repo.

Every push to the main branch triggers a new deploy automatically.
